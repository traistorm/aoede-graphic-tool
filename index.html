SLP Studio là gì?

Công cụ web client-side để đọc, xem, xuất ảnh và tạo file .slp cho Age of Empires 1 (1997) và AoE1: Definitive Edition.

Version hỗ trợ

  • 2.0N — AoE1 gốc (palette index 1 byte)
  • 3.0 — AoE1:DE terrain/rescale (palette index 1 byte)
  • 4.0X — AoE1:DE (palette index 1 byte, có thể có layer phụ)
  • 4.1X — AoE1:DE (display modifier + palette index 2 byte)
  • 4.2P — container LZ4 bọc ngoài file SLP bình thường (Update 38862+)

Quy trình import

  1. Chọn nhiều PNG (mỗi ảnh = 1 frame).
  2. App đọc pixel, tìm màu gần nhất trong palette, gom lệnh tối ưu (Fill, Greater/Lesser draw/skip).
  3. App tự build file SLP, sau đó đọc lại để so khớp từng pixel — nếu lệch thì báo lỗi cụ thể (frame, dòng, cột).
  4. Khi validation pass, file .slp mới được cho tải xuống.

Bảo mật dữ liệu

Toàn bộ xử lý chạy trong trình duyệt của bạn. File .slp và .pal không bao giờ được upload lên server.
